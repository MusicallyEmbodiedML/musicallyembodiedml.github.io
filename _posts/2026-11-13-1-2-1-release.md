A new batch of firmwares has just been released, including updates to existing releases.  There are updated docs [here](/memlnaut).

## Updates to NISPS

Included in all firmwares. The major change is that all methods of exploring and perturbing the behaviour of the network are focused on the network weights, instead of adding to or modulating the outputs. This creates a more consistent experience, and solves issues with the duality of using both a model and the temporary modified outputs of the model.

- exploration noise modulates the model weights, to create more meaningful changes
- jolt pulls the model in new directions with 'pseudo-likes', creating more significant and meaningful changes

Other new features:

- dislikes steer the model based on existing preferences
- the focus screen allows you to explore subsets of the parameter space
- the enable screen lets you turn on and off elements of the audio processing
- likes are saved with models
- general performance improvements; NISPS runs much faster than before
- graphics update - a smooth GUI
- USB MIDI on relevant firmwares

## Updated firmware features

- PAF synth has USB MIDI
- VerbFX and LiveFX add an input gain control and level monitoring

## New firmwares

- *Paramsite* pulls together some experiments with MIDI control into a single system, with presets for popular synths, and customisation controls for others. It shows as USB MIDI port, along with the hardware MIDI ports.

- *MixmasterMEML*, based on MEMLCelium, is a glitch ambient machine, an experiment with navigating multiple musical parts with NISPS.

- *Infinibits* is a drone synth

- *NautLinear* is a nonlinear tone and harmonics processor

- *VoiceFX* is an effects unit based on LiveFX, and targetted specifically at voice processing
